Session economics · every assumption on the table

Agents don't pay to think.
They pay to remember.

A cost forensic of one real agent session (7 minutes, one code-review task, 257 lines of local logs): the visible "generation" is only 15% of the bill. The other 85% goes to the same thing — reading history back into context, over and over. 89.3% of input traffic is cache re-reads, 30% of the bill is the first second, a single command ate 16%. Full methodology and error bounds below; reproducible in 30 seconds.

One boundary up front: the provider's bill is correct. ccusage's metering matched ours token-for-token. This page covers what comes after metering — the cost structure visible in the logs that no report computes for you. Self-test script below; token-level review welcome.

The three-step method — works on every agent tool

the method generalizes, not the numbers
STEP 1

Locate the local logs

Every runtime drops sessions in predictable paths: ~/.claude/projects/, ~/.codex/sessions/, ~/.zcode/cli/rollout/… Zero integration, zero code touched.

STEP 2

Dedup by call id

Streaming responses are split into 2–4 records, each carrying the same usage snapshot. Dedup by message.id turns 33 records back into 11 real API calls.

STEP 3

Split into three buckets

fresh input (full price) / cache_read (~1/10 price) / output. Only when the buckets are separate is "where the money went" visible. A merged total is meaningless.

L1 · Internal consistencySame-id duplicate records: 0 usage mismatches; context conservation exposed ±a few hundred tokens of split fuzz per call — so conclusions only at magnitude level.
L2 · Bill reconciliationThe gold standard is the provider's bill, not any log tool. This run had none to reconcile; declared as such.
L3 · Version pinningMethodology verified on Claude Code v2.1.153. Runtimes drift — re-validate per version.

30-second self-test · on your own ~/.claude/projects
python3 - <<'EOF'
import json, glob, os
calls = {}
for fp in glob.glob(os.path.expanduser('~/.claude/projects/*/*.jsonl')):
    for line in open(fp, encoding='utf-8'):
        try:
            r = json.loads(line)
        except ValueError:
            continue
        if r.get('type') != 'assistant':
            continue
        m = r.get('message') or {}
        u = m.get('usage')
        if not (m.get('id') and u):
            continue
        calls[m['id']] = u  # dedup by message.id
fresh = sum(u.get('input_tokens', 0) for u in calls.values())
cache = sum(u.get('cache_read_input_tokens', 0) for u in calls.values())
out   = sum(u.get('output_tokens', 0) for u in calls.values())
print(f"API calls: {len(calls)} | fresh: {fresh:,} | cache: {cache:,} ({cache/(fresh+cache):.0%}) | out: {out:,}")
EOF
